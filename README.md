BandUp AI is an AI-powered educational platform designed to improve students’ IELTS and SAT scores through personalized learning, adaptive practice tests, instant feedback, and AI-driven performance analysis. The platform helps students identify weaknesses, track progress, and achieve their target scores more efficiently.
## What technologies are used for this project?
This project is built with:
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
